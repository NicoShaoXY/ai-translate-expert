浏览器笔记

内置翻译能翻整页，但翻不了一句

Chrome 自带的翻译功能会整页接管：识别语种、弹出提示条、把整篇文本替换掉。这对读长文很方便，可当你只想确认某个术语时，它显得过重。

Built-in translation rewrites the whole document, which is convenient for long reads but heavy for a single sentence.

于是又回到划词即译：选一段、弹出译文、看完即走，不动页面结构。原版扩展当年解决的正是这件事，这也是它被复刻的原因。

卡片状态

同一套组件在加载、成功、失败三种情况下的表现

触发方式

划词浮标、右键「翻译所选文字」、快捷键 Alt+T（macOS 为 Option+T）三条路径，均走同一个翻译通道。

卡片内操作

切换目标语言即时重译、复制译文、朗读、固定位置、编辑原文后重译，Esc 关闭。

整页翻译

先按 html lang 与文字脚本比例判定语种，仅当页面不是中文时触发；按段落合并请求，顶部提示可一键还原原文。

双语对照

开关默认关闭。关闭时页面只显示译文、不留对照节点；随时切换会清掉已插入的对照内容并按新模式重排。

AI 翻译模式

选服务商、贴密钥即可，接口地址由预设带出；缺项会被明确拦住并提示缺哪一项，保存时自动跑一次连通性测试。

隔离与隐私

样式挂在 shadow DOM 内，不污染页面；正文只发往 Google 翻译接口，不做本地留存。
